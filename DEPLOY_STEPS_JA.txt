【Vercel版 ver.11.1 導入手順】

1. GitHubを開く
2. New repository
3. Repository name: batting-form-analyzer-vercel
4. Create repository
5. Add file → Upload files
6. このZIPを解凍し、「batting-form-analyzer-vercel-v11」フォルダの中身を全部アップロード
   ※フォルダ自体ではなく、中の frontend / backend / vercel.toml / README.md などをアップロード
7. Commit changes

8. Vercelへ戻る
9. Add New → Project → Import
10. batting-form-analyzer-vercel をImport
11. Root Directoryは「./」のまま
12. Deploy

13. VercelのProjectを開く
14. Storage → Blob → Create / Connect Store
15. 作成したBlob StoreをこのProjectへ接続
16. 再Deploy

17. 公開URLの末尾に /api/health を付ける
    例: https://xxxxx.vercel.app/api/health
18. {"ok":true,"version":"11.1"...} と出ればPython API接続成功
19. トップURLをスマホSafari/Chromeで開いて動画解析をテスト

※ MediaPipe/OpenCVが大きすぎるというDeployエラーの場合
Project → Settings → Environment Variables
VERCEL_SUPPORT_LARGE_FUNCTIONS = 1
を追加してRedeploy。

20. 解析結果の「今回優先して確認したいポイント」で「参考動画を見る」ボタンが表示されることを確認
